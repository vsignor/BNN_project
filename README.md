# KRL: *"Fitting Binarized Neural Networks"*
Project developed for the Knowledge Representation and Learning course, A.Y. 2023–2024.
University of Padua – Master's Degree in Data Science, *Machine Learning for Intelligent Systems curriculum*.

## 🧩 Project Description
Research project focused on the development of a Max-SAT formulation for the construction, training, and evaluation of Binarized Neural Networks (BNNs), including architectures composed of multiple stacked binarized layers.
